# Gupta Paper Stores — Digital Khata App

India ka #1 Free Digital Ledger/Khata Management Platform for small and medium businesses.

## Features

- **Customer Management** — Add, edit, delete customers; search/filter by balance type
- **Transaction Ledger** — Record credit/debit entries, filter by customer/type, CSV export
- **UPI Payment Tracking** — Track UPI, cash, bank transfer and cheque payments
- **SMS Reminders** — Send payment reminders with Hindi/English templates
- **Reports & Analytics** — Charts, monthly trends, category breakdown, PDF/CSV export
- **Admin Panel** — System health monitoring, user registrations, business metrics

## Tech Stack

- **Framework**: Next.js 16 (App Router, TypeScript)
- **Styling**: Tailwind CSS v4
- **Charts**: Recharts
- **Icons**: Lucide React
- **Data**: Sample mock data (no backend required)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

```bash
npm run build   # Production build
npm run start   # Start production server
```
